# Avara

`Avara-Bold.woff2` is vendored from the upstream project at
<https://gitlab.com/velvetyne/Avara> (`fonts/webfonts/Bold/`), unmodified.
Licensed under the SIL Open Font License 1.1 — see `OFL-Avara.txt`.

It is the display face of the `paper` theme, which dresses the app in the look
of Stonetop's own printed sheets. Nothing else uses it, and no other theme
loads it: a browser only fetches a face that rendered text actually asks for.

The body face of that theme is Libre Caslon Text, a free stand-in for the Adobe
Caslon Pro those sheets are set in. It comes from npm (`@fontsource/libre-caslon-text`)
rather than being vendored here.
